# 实机测试 Checklist（方式 B：本地电脑连交换机）

> **前提**：本地 SDK 已编译完成（build/bin 下有 h1_loco_client 等可执行文件）
> **目标**：首次连接真实 H1-2，验证通信，安全测试

---

## ⚠️ 第 0 步：安全准备（必做！）

- [ ] 机器人**挂吊绳**
- [ ] 找到**急停按钮**，手随时能碰到
- [ ] 周围**清空**障碍物和人员
- [ ] 确认机器人已上电，启动完成（关节锁住、指示灯稳定）

---

## 第 1 步：物理连接（需要网线）

- [ ] 网线一端插 **H1 交换机**，一端插**电脑有线网口**（enp114s0）
- [ ] 确认网卡 UP：
  ```bash
  ip addr show enp114s0
  ```
  看到 `state UP` 才继续。

---

## 第 2 步：配置静态 IP

```bash
# 1. 查看有线连接名
nmcli connection show

# 2. 配置静态 IP（假设连接名是 "Wired connection 1"）
sudo nmcli connection modify "Wired connection 1" ipv4.method manual ipv4.addresses 192.168.123.99/24

# 3. 激活连接
sudo nmcli connection up "Wired connection 1"

# 4. 确认 IP 生效
ip addr show enp114s0
```

**成功标准**：`enp114s0` 下出现 `inet 192.168.123.99/24`。

---

## 第 3 步：测试连通性

```bash
ping 192.168.123.161
```

`192.168.123.161` = 运控 PC1。
**成功标准**：收到 `64 bytes from 192.168.123.161 ...` 回复。

> 如果 ping 不通，检查：网线是否插紧、IP 是否配对、机器人是否上电完成。

---

## 第 4 步：安全命令测试（只读，不触发动作）

```bash
cd ~/unitree_sdk2/build/bin

# 查询当前状态机编号（只读，安全）
./h1_loco_client --network_interface=enp114s0 --get_fsm_id
```

**成功标准**：打印 `current fsm_id: xxx`（比如 1=Damp）。

再查几个只读参数：

```bash
./h1_loco_client --network_interface=enp114s0 --get_balance_mode
./h1_loco_client --network_interface=enp114s0 --get_stand_height
```

**能读到数值 = 通信完全打通！**

---

## 第 5 步：安全动作测试（有吊绳后）

```bash
# 阻尼模式（电机松劲，可手动摆）—— 最安全的动作
./h1_loco_client --network_interface=enp114s0 --damp

# 站起来（确保吊绳拉住）
./h1_loco_client --network_interface=enp114s0 --stand_up

# 进入行走状态
./h1_loco_client --network_interface=enp114s0 --start
```

**⚠️ 注意**：
- 每个命令之间**等 2-3 秒**，观察机器人反应
- 任何异常（异响、抖动、失控）**立刻按急停**
- 动作测试全程**吊绳保护**

---

## 第 6 步：收尾

```bash
# 停止移动
./h1_loco_client --network_interface=enp114s0 --stop_move

# 回到阻尼（松劲）
./h1_loco_client --network_interface=enp114s0 --damp
```

---

## 故障排查速查

| 问题 | 可能原因 | 解决 |
|------|---------|------|
| ping 不通 | 网线没插紧 / IP 没配好 / 机器人没上电 | 检查连接和 IP |
| `get_fsm_id` 超时 | 网卡名传错 / 机器人服务未启动 | 确认网卡名是 enp114s0 |
| 命令无响应 | SetTimeout 太短 / 机器人状态异常 | 加 --get_fsm_id 先看状态 |
| 机器人抖动 | 吊绳拉扯 / 参数问题 | 立刻急停，检查 |
