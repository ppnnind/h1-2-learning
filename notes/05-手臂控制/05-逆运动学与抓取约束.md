# H1-2 逆运动学与抓取约束

**日期**：2026-09-06  
**对应阶段**：阶段 5 - H1-2 手臂控制  
**前置笔记**：`04-H1-2手臂关节模型与正运动学.md`  
**状态**：逆运动学概念已学习；求解器选型和离线程序待完成

> 本节只讨论离线计算和安全检查，不向机器人发布命令。IK 求解成功不等于允许实机执行。

## 1. 正运动学与逆运动学

```text
正运动学 FK：关节角 q → 末端位姿 T
逆运动学 IK：目标末端位姿 T → 一组关节角 q
```

实用 IK 的输入通常包括：

- 目标位置和姿态。
- 当前关节角或其他初始猜测 `seed`。
- 关节上下限。
- 位置和姿态误差阈值。
- 可能还有碰撞约束、姿态偏好和迭代次数限制。

输出不应只有关节角，还应包括求解是否成功、最终误差和失败原因。

## 2. 为什么存在多组解

单只 H1-2 手臂有 7 个关节，末端位姿包含 6 个约束：

```text
位置：x、y、z
姿态：3 个自由度
```

因此，同一个手腕位姿通常可能对应多组关节姿态。如果腰部 yaw 也参与，冗余自由度更多。

多余自由度可以用于：

- 远离关节极限。
- 避免肘部靠近躯干。
- 保持姿势接近当前状态。
- 避免自碰撞。
- 为后续接近或抬升动作保留活动空间。

## 3. `seed` 的作用

数值 IK 通常从一组初始关节角开始迭代。使用当前实际关节角作为 `seed`，可以让求解器优先寻找附近的解，降低突然切换到另一种肘部姿态的可能性。

但 `seed` 只是搜索起点，不是安全保证。不同初值可能得到不同解，也可能出现某个初值失败而另一个初值成功。

## 4. 抓取目标坐标系

视觉和抓取规划通常给出手掌或抓取点的目标位姿：

```text
T_base_target_palm
```

H1-2 无手模型当前只计算到手腕。若 Dex5 安装变换为：

```text
T_wrist_palm
```

则手臂 IK 的手腕目标应为：

```text
T_base_target_wrist
  = T_base_target_palm * inverse(T_wrist_palm)
```

如果 `T_wrist_palm` 不准确，即使手腕关节完全执行计算结果，实际手掌和指尖也不能准确到达抓取位姿。该变换必须来自确认过的模型、机械数据或标定结果。

## 5. 数值 IK 的基本过程

当前关节角为 `q`，目标位姿与当前位姿之间的误差为：

```text
e = [位置误差, 姿态误差]
```

求解器反复执行：

```text
使用 q 做 FK
→ 计算末端误差 e
→ 使用 Jacobian 计算关节修正量 Δq
→ 限制修正量并更新 q
→ 重新计算误差
→ 误差满足阈值则返回成功
```

Jacobian 描述关节小幅变化与末端位置、姿态小幅变化之间的关系：

```text
Δx ≈ J(q) * Δq
```

它只是在当前姿态附近的局部线性关系，不代表一次计算就能直接获得完整目标解。

## 6. 奇异状态

接近奇异状态时，Jacobian 在某些方向上失去有效控制能力。为了消除很小的末端误差，求解器可能计算出很大的关节修正量，出现：

- 迭代不稳定或不收敛。
- 关节角变化突然增大。
- 对测量和数值误差非常敏感。
- 在不同姿态解之间跳动。

常见缓解方法包括：

- 阻尼最小二乘。
- 限制单次迭代的最大 `Δq`。
- 检查 Jacobian 的条件数或最小奇异值。
- 更换 `seed`。
- 调整目标姿态或接近方向。

阻尼能够抑制过大的关节变化，但可能增大最终末端误差。

## 7. 抓取不是只求一个 IK

完整抓取至少包含：

```text
当前姿态
→ 预抓取位姿
→ 沿安全方向接近抓取位姿
→ 闭合灵巧手
→ 抬起位姿
```

每个关键位姿都可能单独存在 IK 解，但这些解还必须能够连续连接。可依次传递 `seed`：

```text
当前关节角
  → 预抓取解
      → 以预抓取解为 seed 求抓取解
          → 以抓取解为 seed 求抬起解
```

这样有助于维持同一姿态分支，但仍需对完整路径做插值、限位和碰撞检查。

## 8. IK 成功后的必要检查

求解器返回成功后，至少检查：

1. 所有关节角都是有限数，没有 `nan` 或 `inf`。
2. 所有关节角位于更保守的软件软限位内。
3. 用 FK 回算后，位置和姿态误差满足明确阈值。
4. 解与当前姿态的差值没有异常跳变。
5. 没有接近不可接受的奇异状态。
6. 完整路径中不存在自碰撞或环境碰撞。
7. 路径上每一点都满足关节限制。
8. 已生成连续且受限的速度、加速度轨迹。
9. 实机执行器具备状态超时、跟踪误差和停止处理。

只验证最终关节角不够：从当前姿态运动到目标姿态的中间路径也可能越界或碰撞。

## 9. 三个不同层次不能混为一谈

```text
IK：找到一个能到达目标位姿的关节配置
路径规划：找到从当前配置到目标配置的无碰撞路径
轨迹与控制：按受限速度和加速度跟踪这条路径
```

IK 成功只解决第一层问题。

## 10. 对当前开发顺序的影响

在编写任何 DDS 手臂运动程序前，先完成离线运动学验证：

1. 固定并加载正确版本的 H1-2 无手模型。
2. 明确基座、手腕和未来 Dex5 手掌坐标系。
3. 用已知关节角计算 FK，并可视化检查模型姿态。
4. 给定目标手腕位姿求 IK。
5. 用 FK 回算验证 IK 结果。
6. 检查关节限位、解连续性和奇异性指标。
7. 后续再加入碰撞检查和轨迹规划。

这些步骤完全离线，不需要机器人产生动作，但产物能够直接复用于预抓取、抓取和抬升位姿求解。

## 11. 已掌握的关键点

- 7 自由度手臂求 6 维末端位姿通常存在多解。
- 当前关节角可作为 `seed`，帮助获得附近且连续的解。
- Jacobian 描述关节微小变化与末端位置、姿态微小变化的关系。
- 奇异状态可能让很小的末端误差对应很大的关节变化。
- 冗余自由度可以用于避限位、自碰撞和不自然肘部姿势。
- 抓取需要连续的预抓取、抓取和抬升解，而不是单个孤立目标。
- IK 成功不代表路径安全，也不代表可以直接发送给实机。
