## 编译方法

每个子目录都有自己的 CMakeLists.txt，编译方式：

```bash
cd 01-helloworld
mkdir build && cd build
cmake ..
make
```

## ⚠️ 安全提醒

- 涉及实机控制的代码，**先在仿真或挂吊绳状态下测试**
- 底层控制代码运行前，确认急停按钮位置
- 不确定的参数值，先问再跑
